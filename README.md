库街区 · 1.8.14
面向 HarmonyOS 的 ArkTS/ArkUI 非官方社区客户端，目标 HarmonyOS API 26。作者 Kevin，与库洛游戏无隶属或授权合作关系。

本版修复/补充：
- 评论区增加作者头像显示，点击头像或昵称可进入原生用户主页；支持楼中楼作者。
- 评论发布新增图片选择、上传及图文提交流程，仍需真实账号和服务端验收。
- 延续用户主页、帖子列表、关注与取关、关注关系刷新、草稿保存、图片预览和视频播放等功能。
- 关注状态优先通过已登录账号的关注列表核对，避免每次进入主页都误显示为未关注。
- 继续保留登录凭证保护，防止网页中的不同账号凭证静默覆盖原生会话。
已知限制：
- 评论删除接口尚未核实，本版不能删除评论。
- 其他用户的关注数、粉丝数及完整名单仍可能无法正确获取；不展示未经身份核实的统计。
- 图片评论是否被服务端接受、视频上传是否稳定、关注状态跨页面同步仍需真机测试。
- 游戏真实流量转发、HTTPS 解密与抽卡记录授权提取尚未实现；现有网络测试不等于完成游戏接入。
- 不提供未经验证的个人资料编辑写入接口，也不保证服务端 Token 自动续期。
更新方法：

解压后打开 Kujiequ 文件夹，双击 Update.cmd，选择原工程根目录。更新器先备份再替换；成功后自动关闭，失败时保留错误信息并写入 Update.log。随后在 DevEco Studio 中同步工程、重新构建并运行。无需主动卸载已安装应用，以免丢失本地数据。
