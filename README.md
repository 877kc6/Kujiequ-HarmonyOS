## 在 Windows / DevEco Studio 打开

1. 解压整个 `Kujiequ` 文件夹，在 DevEco Studio 选择 **Open**，打开包含根 `build-profile.json5` 的目录。
2. 使用支持 API 26 的 DevEco，SDK Manager 中安装正式 `26.0.0` SDK，等待工程同步；如 IDE 提示更新构建模型，使用当前 IDE 生成的模型版本。构建工具与 SDK 由 IDE 安装，不在压缩包里捆绑。
3. 若 IDE 要求初始化 Hvigor wrapper，使用 IDE 的同步 / 初始化功能，或先新建 API 26 的 Empty Ability 工程，将该工程的 `AppScope`、`entry/src/main` 及 SDK 配置移入新工程，保留 IDE 生成的构建工具版本。不要降 SDK 来掩盖代码错误。
4. 在 **File → Project Structure → Signing Configs** 配置自己的签名，使用 API 26 模拟器或支持 API 26 的手机运行 `entry`。包名若修改，签名 Profile 也必须对应。
5. 首先验证游客首页与详情，再进行短信登录。若触发人机验证，先使用官方网页功能，不能把此步骤视为原生登录已完成。
6. 不在工程中上传 `.p12`、`.p7b`、证书密码或用户 token。

底栏通过 HDS 原生组件实现，背景采用全窗口布局，交互内容由 SafePage 读取系统实际避让区进行保护。浅深主题与背景应用于原生页面；官方网页内部仍由网站控制。材质档位与厚度按 API 26 能力配置，实际效果受设备和系统沉浸光感设置影响。
